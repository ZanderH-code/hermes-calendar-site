Privacy Policy

Last updated: 2026-11-09

Zander's Calendar Assistant is a personal tool used only by its owner. It is not distributed to or used by anyone else.

Data accessed

With the owner's explicit consent, the app uses the Google Calendar scope (https://www.googleapis.com/auth/calendar) to read, create and delete events on the owner's own calendar. No other Google data (such as Gmail or Drive) is requested.

How data is used and stored

Calendar data is used only to answer the owner's requests. The OAuth token is stored on the owner's private server with restricted file permissions. Calendar contents are not sold, shared, or used for advertising, and are not used to train AI models beyond processing the owner's own request.

Retention and revocation

The token is kept until the owner revokes access at myaccount.google.com/permissions, after which it is deleted.

This app's use of information from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
